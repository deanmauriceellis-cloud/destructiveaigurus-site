// Understanding Licensing Models

Your platform investment delivers real value —
local AI can help you get even more from it.

Enterprise platforms use well-established licensing models that reflect the comprehensive capability they deliver. Understanding how these models work helps identify where local AI augmentation can complement your platform — extending its value while improving overall ROI.

Pega: Per-Case & Per-User

Pega's case management and decisioning engine is industry-leading for orchestrating complex workflows. It licenses by case type, concurrent user, and decision execution. For high-volume decision workloads, local AI can complement Pega by handling eligible inference tasks — keeping Pega at the center while improving ROI on AI-intensive operations.

Salesforce: Per-User + API Metering

Salesforce excels at CRM, customer engagement, and ecosystem integration. It licenses per user, with AI features and API calls as additional tiers. For organizations with high-volume AI and API workloads, local AI can augment the Salesforce ecosystem — handling eligible operations locally while Salesforce remains the system of record.

SAP: Per-CPU & Named User

SAP delivers deep enterprise resource planning with HANA's in-memory processing power. It licenses by named user type and CPU cores, with SAP AI Core adding per-inference pricing. Local AI can work alongside SAP by handling high-volume inference tasks outside the platform — letting SAP focus on what it does best while extending your AI capabilities.

Oracle: Processor & Named User Models

Oracle provides robust database and enterprise application infrastructure. Its processor-based licensing and Named User Plus models reflect the platform's depth. Local AI augmentation can complement Oracle by running eligible AI workloads on your own infrastructure — keeping Oracle at the center of your data layer while extending its reach.
